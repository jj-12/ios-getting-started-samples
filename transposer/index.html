Transposing the printed notes

A PDF only contains a picture of the notes, so this app can move the chord symbols it finds in the PDF text, but not redraw the notation itself. To transpose the actual notes, convert the PDF to MusicXML once with a free music-OCR tool, then import that file here — transposition, playback and printing all work fully on MusicXML.

  • Audiveris — free, open-source desktop app (Windows/Mac/Linux); exports .mxl.
  • homr — open-source recognizer with an in-browser demo for photos/scans.
  • MuseScore — free notation app; its PDF import produces editable scores you can save as MusicXML.

Recognition quality varies with scan quality — expect to fix a few notes in a notation editor for dense scores.
