# Heads Up! Party Game

A mobile-friendly "Heads Up" style guessing game built as a Progressive Web App. Perfect for playing with family and friends while waiting in line!

## How to Play

1. Set up your teams, choose a timer length, and pick a category
2. Hold the phone to your forehead so others can see the screen
3. Your teammates describe the word without saying it
4. **Tilt DOWN** (nod forward) when you guess correctly
5. **Tilt UP** (lean back) to pass
6. When the timer runs out, the next team goes!

## Features

- 6 word categories (Animals, Food, Disney, Movies, Sports, Around the House)
- Configurable timer (60, 90, or 120 seconds)
- 2-6 teams with score tracking
- Works offline (PWA)
- Tilt detection with tap fallback for desktop
- Audio and vibration feedback
